# 样式失效修改路径

样式失效**100%是路径问题**！核心原因：
VitePress 默认打包为**根目录 /**，但你部署在**子目录 /docs**，资源（CSS/JS）加载路径错误（404），所以没样式。

我分**两步**彻底解决，严格对齐官方配置，零出错：

---

# 第一步：本地修改 VitePress 配置（最关键！）

打开你本地的配置文件：
`merchant-admin/docs/.vitepress/config.js`（或 `.mjs`/`.ts`）

**添加 base 路径**，告诉 VitePress 部署在 `/docs/` 下：

```js
export default {
    // 👇 新增这一行，固定写法，必须加
    base: '/docs/',

    // 你原来的其他配置保留
    title: '文档',
    themeConfig: {
        // ...
    }
}
```

### 重新打包生成正确的 dist

本地终端执行：

```bash
# 进入文档目录
cd merchant-admin/docs
# 重新构建
vitepress build
```

构建后，新的 `dist` 资源路径会自动变成 `/docs/assets/xxx`，样式就正常了。

---

# 第二步：替换最终 Nginx 配置（官方标准 + 修复路径）

直接用这个配置，**完美解决样式/刷新/缓存问题**：

```nginx
# 强制HTTP跳转到HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name youupro.xyz www.youupro.xyz;
    
    access_log /var/log/nginx/youupro_http_access.log;
    error_log /var/log/nginx/youupro_http_error.log;
    
    return 301 https://$host$request_uri;
}

# HTTPS核心配置
server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name youupro.xyz www.youupro.xyz;

    ssl_certificate /etc/nginx/ssl/youupro.xyz/youupro.xyz.pem;
    ssl_certificate_key /etc/nginx/ssl/youupro.xyz/youupro.xyz.key;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_prefer_server_ciphers on;
    ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:ECDHE:ECDH:AES:HIGH:!NULL:!aNULL:!MD5:!ADH:!RC4;
    ssl_session_timeout 10m;
    ssl_session_cache shared:SSL:10m;
    ssl_session_tickets off;
    ssl_stapling on;
    ssl_stapling_verify on;
    resolver 8.8.8.8 8.8.4.4 valid=300s;
    resolver_timeout 5s;

    # VitePress 官方 Gzip 配置
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    access_log /var/log/nginx/youupro_https_access.log;
    error_log /var/log/nginx/youupro_https_error.log;

    # 原有 notes 配置
    location ^~ /notes/ {
        root /home/ski/product/static_html/;
        index index.html;
        try_files $uri $uri/ =404;
    }

    # ==============================================
    # 👇 修复版：VitePress /docs 官方标准配置（样式正常）
    # ==============================================
    location /docs/ {
        alias /home/ski/product/static_html/dist/;
        index index.html;
        
        # 官方 SPA 路由（解决刷新404）
        try_files $uri $uri/ /docs/index.html;
        
        # 错误页
        error_page 404 /docs/404.html;
        error_page 403 /docs/404.html;

        # 官方缓存配置（CSS/JS 永久缓存）
        location ~* ^/docs/assets/ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }

    # Django 代理
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 自定义错误页
    error_page 404 /error_pages/404.html;
    location = /error_pages/404.html {
        root /var/www/youupro.xyz/;
        internal;
    }

    # Django 静态文件
    location /static/ {
        alias /home/ski/product/django/KnowledgeBase/staticfiles/;
        expires 30d;
        add_header Cache-Control "public, max-age=2592000";
    }

    location /media/ {
        alias /home/ski/product/django/KnowledgeBase/media/;
        expires 7d;
    }
}
```

## 为什么之前样式失效？

- 未配置 `base: '/docs/'` → VitePress 打包资源路径为 `/assets/xxx`
- 实际资源路径是 `/docs/assets/xxx` → 浏览器加载404 → 无样式
- 配置 base 后，路径自动修正，样式立即恢复
