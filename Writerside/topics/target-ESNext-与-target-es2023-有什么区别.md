# &quot;target&quot;: &quot;ESNext&quot;, 与 &quot;target&quot;: &quot;es2023&quot;, 有什么区别

### 核心定义

`target` 是 TypeScript 中用于指定**编译后 JavaScript 代码遵循的 ECMAScript 版本**的核心配置，决定了 TS
会对哪些新语法做降级转译、哪些特性原生保留。二者的核心本质差异如下：

- **`ES2023`（也叫 ES14）**：是 ECMAScript 官方在 2023 年 6 月发布的**正式、冻结、固定不变的年度标准版本**，所有纳入的特性均为已完成的
  Stage 4 最终阶段特性，规范永久固定，不会再变更。
- **`ESNext`**：是 TypeScript 提供的**特殊动态目标**，它不对应任何一个固定的 ES 年度版本，永远指向**当前 TypeScript
  版本所支持的最高、最新的 ECMAScript 特性集合**，包括已进入 Stage 3/4、还未纳入正式年度发布的草案特性，会随着 TS 版本和 ES
  提案的推进滚动更新。

---

### 核心差异对比表

| 对比维度        | `ES2023`                                                              | `ESNext`                                                                               |
|:------------|:----------------------------------------------------------------------|:---------------------------------------------------------------------------------------|
| **规范性质**    | 正式发布的标准化规范，永久冻结                                                       | 非标准化的动态特性集合，持续滚动更新                                                                     |
| **稳定性**     | 极高，任何 TS 版本中含义、行为完全一致                                                 | 低，不同 TS 版本支持的特性不同，编译结果可能不一致                                                            |
| **特性覆盖**    | 仅包含 ES2023 正式发布的固定特性（如数组 `findLast`/`toReversed` 等副本方法、Hashbang 标准化等） | 包含 ES2023 全部特性，以及更新的 ES2024/ES2025 特性、甚至部分成熟草案特性（如 `Promise.withResolvers`、装饰器、管道运算符等） |
| **编译转译行为**  | 仅对超过 ES2023 标准的语法做降级转译，ES2023 内的特性全部原生保留                              | 几乎不做任何语法降级，所有 TS 支持的最新语法全部原生保留，不做转译                                                    |
| **运行环境兼容性** | 兼容原生支持 ES2023 的稳定环境（Node.js 20+、Chrome 110+、Firefox 109+ 等）           | 仅兼容最新版浏览器/运行时，部分草案特性甚至需要环境开启实验性 flag 才能运行                                              |
| **行为可预测性**  | 极强，升级 TS、工具链不会改变编译产物的语法标准                                             | 弱，升级 TS 版本可能会新增/修改支持的特性，导致编译产物行为变化                                                     |

### 关键细节补充

1. **TypeScript 官方对 `ESNext` 的明确提示**
   `ESNext` 应谨慎使用，因为它在不同 TypeScript 版本中不代表相同的含义，会让项目的版本升级、工具链适配变得不可预测，生产环境不推荐无脑使用。

2. **对 `lib` 配置的影响**
   `target` 会默认关联对应的 `lib` 类型声明：
    - 设为 `ES2023` 时，TS 会默认加载 `ES2023` 完整的类型声明，不会包含未正式发布的特性类型；
    - 设为 `ESNext` 时，TS 会加载所有 `esnext.*` 相关的类型声明，覆盖最新草案特性的类型支持。

3. **与 Vite 等构建工具的联动差异**
   在 Vite 项目中，二者的差异会被放大：
    - `ES2023` 是稳定的构建目标，Vite 会基于该版本做稳定的语法兼容和压缩优化；
    - `ESNext` 会让 Vite 关闭大部分语法降级，同时启用对最新特性的支持，适合开发环境、面向最新环境的项目，但生产环境可能出现兼容性问题。

### 选型建议

| 场景                     | 推荐配置                                         |
|:-----------------------|:---------------------------------------------|
| 生产环境项目、ToB 业务、库/工具开发   | 优先 `ES2023`（或更低的固定版本，如 ES2022），保证稳定性和兼容性     |
| 开发环境、个人项目、仅面向最新环境的内部系统 | 可使用 `ESNext`，享受最新语法特性                        |
| 多租户 SaaS 外卖商家后台（你的项目）  | 优先 `ES2023`，兼顾现代特性与稳定的兼容性，避免商家使用的浏览器环境出现兼容问题 |
