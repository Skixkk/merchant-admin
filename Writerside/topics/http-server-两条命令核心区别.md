# http-server 两条命令核心区别（简单好懂）
## 1. `http-server`
**默认规则：直接用「当前文件夹」当网站根目录**
你现在 PowerShell 里已经进到了 `webHelpGUIDE2-all` 文件夹，执行这个命令，就会把当前目录下的 `index.html`、静态资源直接启动，**正好适配你现在本地测 Writerside 文档的场景**。

## 2. `http-server ~/my-help`
**手动指定别的文件夹当网站根目录**
不去用你当前所在的文件夹，强行跑去系统用户目录下的 `my-help` 文件夹启动服务；
你本地根本没有这个 `my-help` 文件夹，执行会直接报错、打不开文档。

## 一句话总结
- ✅ **直接输 `http-server`**：用你现在的文档文件夹，**正确可用**
- ❌ **带路径 `http-server xxx`**：跑去别的目录，**你用不上、会报错**

## 补充实操提示
你现在路径完全对，直接敲 `http-server` 就行，不用加任何路径，秒启动本地文档预览。
